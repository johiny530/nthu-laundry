# 碩齋洗衣房即時看板

清大碩齋一樓洗衣機、烘衣機的即時狀態，一頁看完，不用再跑下樓確認。

**https://johiny530.github.io/nthu-laundry/**

## 用法

用手機或電腦打開網址就好，不用登入、不用安裝。狀態會自己更新，不用重新整理。

- **閒置**（綠色）— 可以直接用
- **剛洗好／剛烘好**（黃色）— 已完成，衣服可能還在裡面
- **運轉中**（藍色）— 顯示還要多久
- **失聯**（灰色）— 機器沒有回報，可能故障或斷電

每一區的標題右邊會顯示該類機台目前有幾台可用；全都在跑的時候，改顯示最快多久會有一台空出來。

## 完成時提醒我

點機台右上角的鈴鐺就會開始盯著它，完成時發一則通知，然後鈴鐺自動熄滅。再點一次可以取消。想盯幾台都可以。

要注意兩件事：

- **分頁要留著**才會通知，可以最小化或切到背景，但不能關掉。這個看板沒有伺服器，通知是由開著的網頁自己發出的。
- **iPhone 必須先把網站加到主畫面**，用 Safari 直接開網頁收不到通知（iOS 的限制）。Android 和電腦則不用。

如果通知沒出現，按畫面上的「測試通知」，它會直接告訴你是卡在瀏覽器權限還是被系統擋掉。

## 機台

洗衣機 6 台、烘衣機 4 台。烘 2 長期失聯（QR 貼紙也毀損，機器可能故障）。

可以加到手機主畫面，像 App 一樣開。
